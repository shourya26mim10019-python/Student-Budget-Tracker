# Statement of the Project

## Problem Statement
Many college students get pocket money or some income every month but do not track their expenses leading to overspending on food, entertainment or mobile and facing shortage of money before the month ends. There is a need for a simple system that can help them track their income and expenses and suggest how much money is left.
The system should allow the user to enter their monthly income and common expense categories and calculate their remaining balance and give simple suggestions.

## Scope of the Project
This project encompasses the basic budget tracking needs of college students. It enables the user to enter their monthly income and common expense categories and calculate their remaining balance and give simple suggestions. The project is limited to console based input and output and does not include any graphical interface or online features.

## Target Users
- College students
- Students staying in hostel or away from home
- Anyone interested in tracking simple monthly expenses using basic Python

## High-level Features
- Take student personal details (name, course, year)
- Record monthly income from different sources
- Record expenses under common college categories
- Calculate and display remaining balance
- Give basic suggestions based on spending pattern
- Save the budget record in a text file
