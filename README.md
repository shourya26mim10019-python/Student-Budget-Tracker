# Student College Budget Tracker

## Project Title
Student College Budget Tracker

## Overview of the Project
This is a simple Python project designed for students to manage their monthly budget at college.
They can enter their income and various expenses and the program will calculate their balance, saving or overspending.
In addition, it will suggest some simple recommendations and save the text file with the results.

## Features
- Entering the student's data (name, course and year of study)
- Entering the monthly income (pocket money, scholarships, or other sources of income)
- Entering the costs (food, books, transport, mobile phone, fun, and other expenses)
- Possibility to add an additional expense
- Calculation of the remaining balance
- Some simple recommendations based on the data
- Saving the results in a separate text file called budget_record.txt

## Technologies / Tools Used
- Python 3
- The basic programming constructs: functions, modules, loops, if-else statements, and file handling
- No external libraries

## Steps to Install & Run the Project
1. Make sure that Python is installed on your computer
2. Place all the files (main.py, module1.py, module2.py, and module3.py) in one folder
3. Open the terminal or command prompt
4. Navigate to the folder with the files
5. Type the following command in the terminal:
python main.py
6. Follow the prompts in the program and enter the necessary data.

## Instructions for Testing
1. Open terminal or command prompt
2. Navigate to the folder with the project
3. Type the following command:
python main.py
4. Run the program and enter students data
5. Enter some income data (if no scholarships or other sources of income, enter 0)
6. Enter the expense data for each category
7. Enter yes or no to add an additional expense
8. Check if the program calculates the remaining balance correctly
9. Check if some recommendations appear
10. Enter yes to save the file and make sure that the new text file (budget_record.txt) is created
11. Open the budget_record.txt file and make sure that the data is saved correctly.
